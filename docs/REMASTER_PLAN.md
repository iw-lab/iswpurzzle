## 0. 총평 — "뼈대는 좋다, 신경계가 끊겨 있다"

ChromaFall의 코어 아이디어(낙하 퍼즐 × 색 융합 × 4방향 중력 × 연쇄)는 상업 게임으로 성립하는 조합이다. 문제는 세 층위에 있다:

1. **기능 파손** — hold·데일리 시드·미션 갱신·목표 3종·이어하기(시간제 모드)·통계/업적이 코드상 존재하지만 실제로는 **작동하지 않거나 파손**된 상태. "만들어진 게임"이 아니라 "만들다 만 기능의 박물관"에 가깝다.
2. **수학 붕괴** — 점수는 연쇄^2.5로 폭증하는데 레벨 임계값은 선형 → 레벨(=속도·색상 수·동시 블록 수)이 폭주. 여기에 배율 이중 적용 버그(피버 실질 ×9)가 겹쳐 난이도 곡선이 설계 불능 상태.
3. **신뢰 불가 상태 전이** — 50ms setInterval + 취소 불가 setTimeout 체인 + 가드 없는 async 연쇄 루프. "가끔 이상해지는" 버그의 근원이 전부 여기다.

리마스터 전략: **엔진 분리 → 버그 소탕 → 난이도 재설계 → 재미(juice) 증축 → 메타 루프 완성** 순서. 아래 전부.

## 2. 난이도 재설계 — "확실하게 맞추기"

### 2.1 현재 난이도가 붕괴하는 수학적 이유

- **레벨 폭주**: 임계값은 선형(`1000·L + 200(L-1)` ≈ 1200/레벨)인데 점수는 연쇄^2.5×150 — 10연쇄 한 번 ≈ 47,000점 = **한 방에 수십 레벨 분량**. 게다가 배율 이중 적용(×9)이 이를 다시 증폭. `checkLevelUp`이 단발 if라 1레벨씩만 오르는 것이 오히려 폭주를 가리는 중.
- **레벨 40 = 8칸 보드에 8블록 조각**: line-h7(7칸 폭)은 좌우 이동 자체가 불가능. 셀 처리량 레벨1 대비 ~36배(🅲 추정). 물리적으로 플레이 불능 구간.
- **첫 판부터 5색 + 최소 4매칭**: 초심자 융합 성공률이 낮아 코어 재미(터뜨리기)를 초반 3분 안에 못 느낌.

### 2.2 재설계안 (구체 수치)

**원칙: 레벨 = 속도축, 색상 = 복잡도축, 조각 크기 = 조작축 — 세 축을 분리하고 각자 완만하게.**

| 축 | 현재 | 리마스터 |
|---|---|---|
| 레벨업 기준 | 점수(선형 임계) | **누적 클리어 블록 수**: `40 + 12×L` (점수 인플레와 절연 — 미사용 상수 `BLOCKS_PER_LEVEL` 부활) |
| 낙하 속도 | 1000ms − 20/L, min 200 | 1000ms − 35/L, **min 350ms** (200ms는 다중블록 조작 불능) |
| 색상 수 | L1: 5색 → L16: 8색 | **L1–4: 4색**, L5: 5색, L12: 6색, L20: 7색, **8색 폐지** (4매칭 규칙에서 7색 초과는 융합 빈도 급락 = 재미 급락) |
| 동시 블록 | L2: 2 → L40: 8 | L1: 1, L3: 2, L8: 3, **L15+: 4 상한** (SHAPES_5~8 전체 폐기. 조작 재미는 4까지가 상한 — 그 이상은 스트레스) |
| 최소 융합 | 4 고정 | 4 고정 유지 (변경 없음 — 규칙 단순성이 자산) |
| 가비지 | L10 시작, 45s→20s | L8 시작, 45s→**min 25s**, 예고 배너에 카운트다운 표시 |
| 피버 | 실질 ×9 (버그) | **×3 단일 적용**, 게이지 지급 단일화(#21 수정), 지속 8s 유지 |

**모드별 난이도 정체성**:
- **클래식**: 위 곡선 그대로. 15~25분 생존이 평균 목표.
- **데일리**: 시드 고정(진짜 구현) + 3분 + 전원 동일 조각열 → 순수 실력 경쟁.
- **서바이벌**: 시간 레벨업 **단독**(점수 레벨업 차단) — "10초마다 빨라진다" 약속 이행.
- **퍼즐**: 목표를 달성 가능한 3종(score/clearBlocks/chains)으로 한정하고, 마지막 수 융합 반영(#5 수정) 후 판정.
- **젠**: 게임오버 없음 + 가비지 없음 + 속도 상한 600ms 고정.
- **타임어택**: 데일리와 중복 → **데일리에 흡수하고 제거** (7모드는 과다 — 5모드로 정리).

## 3. 재미·중독성·직관성 증축 (리마스터 코어)

### 3.1 즉각 피드백(Juice) — "손맛" 층

1. **연쇄 사운드 피치 계단 상승** (🅶): 1연쇄 C → 2연쇄 E → 3연쇄 G… 연쇄마다 반음계 상승. 연쇄 중독성의 검증된 공식(뿌요뿌요·Peggle).
2. **하드드롭 타격감**: 스크린 셰이크(2~4px, 80ms) + 착지 파편 파티클 + heavy 햅틱. 현재 hardDrop은 무음에 가까움.
3. **피버 연출 강화**: BGM 템포 1.25× + 네온 파티클 + 보드 테두리 발광. ×3이 "느껴지게".
4. **위험 상태 심장박동**: 상단 3줄 점유 시 저음 하트비트 + 비네트 강화(현재 있는 붉은 오버레이에 오디오 레이어 추가).
5. **락 딜레이 구현**: `LOCK_DELAY: 400` 상수가 이미 있으나 미구현 — 착지 후 0.4초 미세조정 유예. 조작감 체감 최대 항목.

### 3.2 명료성 — "직관" 층

6. **고스트 블록 전체 모양 표시 + hardDrop 물리 일치화**: 분리낙하를 유지한다면 고스트도 셀별 분리낙하 위치를 그대로 표시(#14). *권장: softDrop 착지와 동일하게 hardDrop도 모양 유지 방식으로 통일* — "보이는 대로 떨어진다"가 낙하 퍼즐의 제1 계약.
7. **인터랙티브 튜토리얼 60초**: 첫 실행 시 4매칭→연쇄→하드드롭→홀드 4스텝 강제 체험(스킵 가능). 현재 HelpModal은 자동 노출 없음.
8. **특수블록 첫 등장 카드** (🅶): 9종 각각 첫 등장 순간 슬로모션 + 1줄 설명 카드. 이후 재노출 없음.
9. **다음 조각 미리보기에 색+모양 함께 표시**: 현재는 색 나열이라 조각 모양과의 대응이 불투명.
10. **회전 결과 프리뷰** (🅶): 회전 버튼 홀드 시 반투명 미리보기.

### 3.3 메타 루프 — "내일 또 켜는 이유" 층

11. **데일리 챌린지 진짜 구현**: 시드 주입(#10) + 결과를 데일리 리더보드에 + **연속 참여 스트릭 보상**(3일: 코인, 7일: 스킨 조각). 리텐션의 척추.
12. **미션 일일/주간 리셋**(#11): `dateKey(YYYY-MM-DD / YYYY-WW)`를 persist에 저장, 불일치 시 재생성.
13. **업적 라인 복구**(#12): 통계 4종 갱신 + `processGameResult` 호출 배선 → 이미 만들어진 랭크 시스템(ranks.ts 225줄)이 살아남.

### 후속 수정 (사용자 실사용 제보 반영)

**"블록이 안 내려간다" — 데스크톱 조작 버튼 전면 무반응.**
TouchControls의 ◀ ▼ ▶ 회전 DROP이 전부 `onTouchStart`만 바인딩돼 있어

스모크 테스트가 키보드만 검증해 놓쳤다.

→ Pointer Event로 재작성(마우스·터치·펜 단일 경로) + 홀드 반복 추가.
