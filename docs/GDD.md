## 1-2. 코어 루프

```
연료 칸이 떨어진다(값·표기 다양) → 로켓 5대 중 하나를 탭해 붓는다
   → 합이 딱 1 → 발사! 점수·콤보·행성 기지 진척      → 다음 칸은 더 빠르게
   → 1을 넘김 → 넘침(펑) · 왜 넘쳤는지 식으로 보여 줌 → 콤보 끊김
```

- **한 판 = 60초**(시간 모드·교실 모드). 다른 모드는 §1-3 표.
- **두 개의 시계**(fun-gates B): 문제를 푸는 동안에도 칸은 계속 떨어진다. 문제를 푸는 일 자체가 플레이라서 «게임 안의 문제집»이 아니다.
- **«한 판 더» 유인**
  - 결과 화면에 내 최고 기록, 바로 위 기록과의 차이, 학교 점수 +N이 나온다.
  - «오늘의 발사»는 모두 같은 순서의 칸이라 친구와 바로 비교된다.
  - 행성 기지 수집(8곳)과 로켓 꾸미기 스티커(보상 상점 없음 — 기록 달성으로만 풀린다).
- **메타 루프**: 문제 풀고 이용권 → 판 → 학교 순위 기여 → 첫 화면 맨 위에서 «우리 학교 몇 위».

## 1-3. 핵심 메카닉

### 판
- 아래쪽에 **로켓 5대**가 나란히 선다(대형판 8대). 로켓마다 연료통 용량은 정확히 **1**이고, 옆에 눈금(0 · ½ · 1)이 있다.
- 위에서 **연료 칸**이 하나씩 떨어진다. 칸의 **높이는 값에 비례**한다(0.25면 통 높이의 ¼).
  - 이 높이가 오개념 «분모가 크면 큰 수»를 눈으로 부정한다: 1/8은 납작하고 1/2은 크다.
- 칸에는 **표기 하나**가 적혀 있다: 분수(3/4), 소수(0.75), 백분율(75%). 표기는 색이 아니라 **테두리 모양 + 작은 아이콘**으로도 구분된다(색각 이상 대응).
- 다음 칸 2개를 미리 보여 준다(«다음», «그다음»).

### 조작 (탭 하나가 기본)
| 입력 | 동작 |
|---|---|
| 로켓 탭(88px 이상 넓은 기둥 전체가 단추) | 떨어지는 칸이 그 로켓으로 날아가 부어진다 |
| 보관함 탭 | 지금 칸을 보관함에 넣고, 보관 중이던 칸을 꺼낸다(판당 무제한, 연속 2회 금지) |
| 키보드 `1~5` / `←→`+`↓`(`e.code` 기준 — 한글 상태 대응) | 같은 동작 |
| 아무것도 안 누름 | 칸이 바닥선까지 내려오면 **지금 위에 있는 로켓**에 저절로 부어진다(위치는 «정답 위치 덱»으로 공정하게 돈다) |

### 판정
| 결과 | 조건 | 반응 |
|---|---|---|
| **발사** | 통의 합 = 정확히 1(내부는 1/100 정수로 계산 — 부동소수 오차 0) | 통 위에 식 «1/4 + 0.5 + 25% = 1»을 0.5초 띄우고 즉시 점화 → 로켓이 하늘로 날아감 → 그 자리에 새 로켓이 올라옴. 화면 흔들림·불꽃·점수 날림 |
| 부음 | 합 < 1 | 연료가 출렁이며 눈금까지 차오름. 남은 양을 통 위에 작게 표시(4·5학년 단계만, 6학년·숫자로만 모드에선 숨김) |
| **넘침** | 합 > 1 | 연료가 넘쳐 «푸슉». 그 칸만 깨져 사라지고 통은 그대로. **식 배너 1.5초**: «0.8 + 1/4 = 1.05 → 1보다 커요». 콤보 끊김 |
| 섞어 채우기 | 발사된 통 안에 표기 2종 / 3종 | 점수 ×1.5 / ×2. 바꿔 읽기를 일부러 하게 만든다 |
| 동시 발사 | 2초 안에 로켓 2대 이상 | «더블 발사!» 추가 점수 |

### 막힘 없음 보장(무데드락)
- 칸 생성기는 **지금 남은 양**을 본다. 떨어질 칸의 값은 항상 «어느 통엔가는 넘치지 않고 들어가는 값» 이하로만 나온다.
- 일정 확률(난이도별 표 §1-4)로 «어느 통을 딱 1로 만드는 값»을 낸다. 그 통의 위치는 **정답 위치 덱**(위치 0~4를 2장씩 섞어 하나씩 뽑음)으로 정한다. 뽑힌 통이 비어 있으면 이번엔 딱 1 칸을 내지 않는다(한 통에 몰아 붓기 막기 — §1-4 탐침).
- 시험 `deadlock.test`: 무작위 봇 10,000판에서 «들어갈 통이 0개인 칸» 0회.

### 모드 (기본틀: classic · time · survival + rule · daily · big)
| 모드 | kind | 규칙 | 기록 | 이용권 |
|---|---|---|---|---|
| 🚀 발사 임무 | classic | 행성 8곳 × 5단계 = 40판. 판마다 목표(«로켓 6대 발사», «섞어 채우기 3번», «넘침 없이 4대»). 이어하기 | 단계 | 판 1개 = 1장 |
| ⏱ 60초 발사 대회 | time | 정확히 60초. 넘침 −3초 없음(교실 공정성: 판 길이 고정). 점수 = 단일 정수 | 점수 | 1장 |
| ❤️ 끝없는 우주 | survival | 하트 3. 넘침 −1. 발사할 때마다 떨어지는 속도 +3%. 30대마다 하트 +1(최대 3) | 발사 수 | 1장 |
| 🔢 숫자로만 | rule | 칸 높이가 모두 같고 눈금도 없다 — **숫자를 읽고 계산해야만** 맞춘다. 90초 | 점수 | 1장 |
| 📅 오늘의 발사 | daily | 날짜 시드 — 모두 같은 칸 순서. 하루 1판 기록, 연속 출석 | 연속일 | 1장 |
| 🛸 대형 발사장 | big | 로켓 8대 · 120초 · 전자칠판·PC 권장 | 점수 | 1장 |
| 👥 모둠 릴레이 | (교실) | 1번~6번이 60초씩 차례로. 이름 입력 없음. «다음 사람» 1탭, 건너뛰기 1탭. 결과는 전원 점수 나란히(꼴찌 강조 없음) | 모둠 합계 | 모둠 1판 = 1장 |

### 학년 단계 (홈에서 한 번 고르면 기억)
| 단계 | 값 | 표기 | 교육과정(2022 개정) |
|---|---|---|---|
| 🟢 4학년 | 0.1 단위(0.1~0.9), 1/2 | 분수 x/10, 소수 한 자리 | 4-2 분수의 덧셈과 뺄셈(분모 같은 분수), 소수의 덧셈 |
| 🟡 5학년 | 0.05 단위 + 1/4 · 3/4 · 1/5 · 2/5 … | 분수(약분 안 된 2/4 · 6/10 포함), 소수 | 5-1 약분과 통분, 분수의 덧셈과 뺄셈 · 5-2 분수와 소수 |
| 🔴 6학년 | 위 + 5% · 15% · 35% … | 분수·소수·**백분율** | 6-1 비와 비율(백분율) |

- 1/3 · 2/3 · 1/7처럼 **유한소수가 안 되는 값은 쓰지 않는다**(옛 게임과 같은 원칙 — 0.333…은 초등에서 «같다»를 말할 수 없다).
- 값은 내부적으로 1/100 정수(5, 10, …, 95)다.

## 1-4. 밸런싱 수치

### 낙하 속도(60초 판 · 칸이 위에서 바닥선까지 오는 시간)
| 구간 | 시간 | 낙하 시간 | «딱 1 만드는 칸» 확률 |
|---|---|---|---|
| 워밍업 | 0~15초 | 4.0초 | 60% |
| 본편 | 15~45초 | 3.0초 | 45% |
| 스퍼트 | 45~55초 | 2.2초 | 40% |
| 카운트다운 | 55~60초 | 2.2초 + 화면·소리 경보 | 40% |

- 탭하면 칸은 0.18초 만에 날아가 부어진다(기다림 없음). 그래서 잘하는 아이는 낙하 시간보다 훨씬 빨리 넣고, 그만큼 칸을 더 받는다 — **실력 = 속도 × 정확도**.
- 끝없는 우주: 낙하 3.5초에서 시작해 발사할 때마다 ×0.97, 최소 1.2초.

### 점수(정수 · 결정론)
| 항목 | 점수 |
|---|---|
| 발사 | 100 + 칸 수 × 20 |
| 섞어 채우기 | 2종 ×1.5 · 3종 ×2 |
| 콤보(연속 발사, 넘침 없음) | n번째 발사 +10%씩, 최대 ×2 |
| 동시 발사 | 2대 +150 · 3대 이상 +400 |
| 넘침 | 0점(감점 없음 — «벌이 아니라 상» 원칙) · 콤보만 끊김 |
- 60초 이론 상한(상수로 박고 클램프): 칸 최대 수 = 60 / 0.18 ≈ 333 → 실제로는 생성 간격 하한 0.5초 → 칸 ≤ 120, 발사 ≤ 60 → **상한 60 × (100+80) × 2 × 2 + 보너스 = 50,000점**. 그 이상은 서버·화면 모두 거부.
- `window.__gameScore = { score, durationMs, version: 1 }` + `opener.postMessage`.

### 봇 기대치 (탐침 실측 · 600판 평균 · Phase 4에서 진짜 코어로 다시 재서 계산기 자동 블록으로 교체)
| 봇 | 60초 발사 수 |
|---|---|
| 0% 봇(아무것도 안 누름 — 저절로 부어짐) | 2.5 |
| 무작위 봇 / 가운데만 누르는 봇 | 4.7 / 4.7 |
| 45% 정답 · 2.0초 | 6.8 |
| 60% 정답 · 1.8초 | 8.5 |
| 85% 정답 · 1.5초 | 11.8 (45% 봇의 **1.75배**) |
| 어른 95% · 0.7초 | 25.9 |
- 탐침에서 고친 구멍 두 개: ① «딱 1 칸»을 비어 있는 통 기준으로 내면 1.00짜리 칸이 나와 무작위 봇이 발사를 공짜로 얻었다 → 딱 1 칸은 **이미 연료가 든 통**에만, 값 ≤ 0.9. ② «딱 1 칸»의 대상 통을 «연료가 든 통 중에서» 고르면 한 통에만 몰아 붓는 봇이 11.7대를 얻었다 → 대상은 **위치 덱이 고른 통이 연료가 들어 있을 때만** 쓴다.
- 칸 사이 최소 간격 0.6초(빨리 눌러도 칸은 0.6초마다).
- 넘침 때 «통을 비우는» 벌도 재 봤다: 무작위 봇 4.7→3.3, 45% 봇 6.8→5.7로 둘 다 깎인다. 무작위 봇 대비 격차는 0.69→0.59배로 조금 좋아지지만 못하는 아이가 더 아프다(«벌이 아니라 상» 원칙) → **넣지 않는다**. 끝없는 우주 모드만 하트로 대신한다.

### 경제
- 재화·상점·룰렛·패스·젬 **전부 없앤다**(옛 게임의 룰렛·배틀패스는 아동용 가챠 금지 규칙에 걸린다).
- 보상은 기록으로만: 행성 기지 8곳, 로켓 스킨 12종(조건: «섞어 채우기 10번», «더블 발사» 등), 스티커 도감.

## 1-5. UI/UX

### 플레이 화면
- 위: 모드 띠(시간 · 점수 · 콤보) — 핵심 수치는 1080p에서 96px 이상.
- 가운데: 떨어지는 칸 + 다음 2개 + 보관함(왼쪽).
- 아래: 로켓 5대. **필수 터치 요소는 세로 25~75% 구간**에 두어야 하므로, 로켓 기둥 전체(발사대에서 낙하 영역까지)를 탭 영역으로 잡는다.
- 전자칠판 가로 여백: 왼쪽에 도키(마스코트 반응), 오른쪽에 모둠 순서 로스터·내 기록.
- 폰 세로: 로켓 5대가 화면 폭을 나눈다(칸 ≥ 64px — 폰은 44px 기준), 여백 패널은 접는다.

### 결과 화면(3초 안에 도착)
- 점수(큰 글씨) · 발사 수 · 섞어 채우기 수 · 넘침 수 · **«이번 판에 넘친 식» 최대 3개 다시 보기**(오답 각인).
- 🏫 «○○초 +2점» 토스트 · [다시 하기] 1탭 · [홈].

### 전환·반응
- 첫 입력 100ms 안에 소리 + 움직임.
- 발사: 히트스톱 60ms → 화면 흔들림 → 로켓 상승(0.8초) → 별 가루.
- 넘침: 통이 붉게 번쩍(초당 3회 미만) + «푸슉» + 식 배너.
- 도키: 발사 땐 환호, 넘치면 «앗!», 콤보 5 이상이면 춤.

## 1-7. 교육 연동

- **문제가 곧 결과를 정한다**: 발사(=점수)는 오직 «합이 1»을 맞혀야 일어난다. 0% 봇은 발사를 거의 못 한다(D-1).
- **오개념 5종 → 규칙**
  | 오개념 | 게임이 드러내는 방법 |
  |---|---|
  | 분모가 크면 크다(1/8 > 1/2) | 칸 높이가 값 그대로. 1/8은 납작하다 |
  | 분자끼리·분모끼리 더하기(1/2+1/2=2/4) | 1/2 두 개를 부으면 통이 꽉 차 발사된다 — «2/4»가 아니라 «1» |
  | 표기가 다르면 다른 수(1/4 ≠ 0.25) | 섞어 채우기 보너스 + 넘침 배너가 표기를 하나로 바꿔 보여 준다(«1/4 = 0.25») |
  | 분수는 늘 1보다 작다 | 넘침 배너에서 «1.05 → 1보다 커요»처럼 1을 넘는 값을 본다 |
  | 약분 안 된 분수 낯섦(6/10) | 5학년 단계부터 2/4 · 6/10 · 15/20 같은 표기가 섞여 나온다 |
- **약점 더 자주(더 어렵게는 아니다)**: 그 판에 넘친 값의 표기를 다음 칸에 1.5배 더 자주 낸다. 판이 끝나면 넘친 식을 다시 보여 준다.
- **문제 풀고 이용권**: 기본틀 허브의 수학 문제(학년 4~6). 5문제 중 4개 정답 → 이용권.
- 학습 이력은 기기에만(localStorage): 값·표기별 넘침 횟수 → «내 약점» 카드.

## 1-8. 완료 기준 (각 줄 = Phase 4 시험 1개)

**판·규칙**
- [ ] 로켓을 탭하면 떨어지던 칸이 0.25초 안에 그 로켓 통에 들어가고 통의 양이 그 값만큼 오른다
- [ ] 통의 합이 정확히 1이면 로켓이 발사되고 그 자리에 빈 로켓이 올라온다(1/4+0.5+25%, 3/5+0.4, 45%+0.55 각각)
- [ ] 합이 1을 넘으면 그 칸만 사라지고 통의 양은 그대로이며, 식 배너가 1.5초 이상 보인다
- [ ] 0.1+0.2+0.7처럼 부동소수 오차가 나는 조합도 정확히 발사된다
- [ ] 무작위 봇 10,000판에서 «어느 통에도 안 들어가는 칸»이 0번이다(무데드락)
- [ ] 아무것도 안 누르면 칸이 바닥선에서 지금 아래 로켓에 저절로 들어간다
- [ ] 보관함은 연속 2회 바꾸기가 막힌다
- [ ] 60초 판은 실력과 관계없이 60.0초(±0.1)에 끝난다
- [ ] 같은 날짜의 «오늘의 발사»는 두 기기에서 같은 칸 순서를 낸다

**학습 게이트(fun-and-learning-gates §D)**
- [ ] D-1: 0% 봇 · 무작위 봇 · 가운데만 누르는 봇이 모두 60초 판 발사 ≤ 5대 이고 45% 봇의 0.75배 이하
- [ ] D-2: 85% 봇 / 45% 봇 발사 수 비 ≥ 1.4 (n ≥ 500, 공통 난수 — 탐침 1.75)
- [ ] D-3: 판 시간 중 연료 칸(=문항)이 화면에 있는 비율 ≥ 95%
- [ ] D-5: 넘침 배너 ≥ 1.5초 + 그 표기 재출제 가중 1.5배
- [ ] D-6: `check-question-variety.mjs` rc 0 (실제 출제 순서 표본)
- [ ] D-7: «딱 1 만드는 통의 위치» χ² 균등(`check-answer-balance.mjs`)
- [ ] 이 게이트들에 옛 버그(높이 없음·위치 쏠림·딱1 확률 0)를 주입하면 빨개진다

**기본틀(gate-baseline S1~S6 · B1~B8)**
- [ ] 첫 화면 맨 위에 학교 순위(상위 5 + 우리 학교)가 보인다
- [ ] 시작 단추 → 문제 5개 → 4개 이상 맞히면 이용권 → 판 시작(차감 1회, 연타해도 1회)
- [ ] 판 끝나면 학교 점수 반영 토스트, 중간에 나가면 환불
- [ ] 전체화면 단추가 있고 판에 들어가면 자동 전체화면이 된다
- [ ] 모드 카드 6종이 같은 높이·같은 모양이다

**교실 트랙**
- [ ] 페이지 로드 → 첫 입력 가능 3초 이내(Fast 3G)
- [ ] 초기 로드 2MB 이하(실측)
- [ ] 1920×1080에서 점수·시간 ≥96px, 본문 ≥48px, 터치 타겟 ≥88px, 필수 요소는 세로 25~75%
- [ ] 모둠 릴레이 6명 교대 · 1명 건너뛰기 · 결과 표에 전원 점수
- [ ] 한글 입력 상태에서 키보드 조작(`{key:"ㄱ", code:"KeyR"}` 류)이 된다
- [ ] 결과에서 1탭으로 다음 판
- [ ] `window.__gameScore`가 정수로 나온다

**화면·품질**
- [ ] 브라우저 콘솔 에러 0건(모든 모드 첫 동작까지 실제로 밟음)
- [ ] 폰 세로(390×844)·폰 가로(915×412)·태블릿(1024×768)·전자칠판(1920×1080) 스크린샷 검수
- [ ] 소리: 첫 탭 뒤 BGM·효과음이 난다(오디오 언락), 이음매 게이트 통과
- [ ] 캐릭터 리그 게이트(`gate-char-rig.mjs`)·이미지 엔진 게이트(`check-image-engine.mjs`)·3D 출처 게이트 PASS
- [ ] 배포 뒤 `gate-baseline --url <배포본> --expect-hub` PASS

## 1-9. 성능 예산

| 항목 | 상한 |
|---|---|

## 1-10. 네트워크

- 동시 접속 플레이 없음(핫시트). 서버는 기본틀 허브(학교 순위·이용권)만 — daum 계정 Worker + D1, 기존 키트 그대로.
- 옛 Firebase 전역 랭킹(자유 이름 입력)은 **없앤다**(아동 개인정보 규칙).

- 킹수학 등재 갱신: 새 제목·썸네일·링크. 로그인은 사용자가 직접 한다.
- 옛 코드는 `legacy/` 태그로만 남긴다(git 이력).
