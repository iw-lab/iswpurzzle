## 3. 2023~2026 아이들 캐주얼 퍼즐 공통점 (레인 합의)
1. 합칠수록 커지는 성장감과 과한 연출
2. 즉각 반응(물리·흔들림·소리)
3. 1~2분 판 + 1탭 재시작
4. 화면 전체가 한눈에 보여 **옆에서 훈수**가 된다(교실에서 특히 중요)
5. 수집·꾸미기 메타(가챠 말고 기록 보상으로)

## 4. 분수 오개념 5종 → 규칙 (GDD §1-7 표로 옮김)
분모가 크면 큼 · 분자끼리 분모끼리 더하기 · 표기가 다르면 다른 수 · 분수는 1보다 작음 · 약분 안 된 분수 낯섦.

## 5. 수박식 «같은 값 2개 → 2배» 를 분수에 쓰면 (레인 지적)
- 분모가 작아지는데 블록은 커져 혼란. 1/3·1/5가 섞이면 영원히 안 합쳐져 판이 막힌다.
- 결과가 «임의 합성»으로 읽혀 덧셈 원리가 안 보인다.
→ **«합이 정확히 1»** 규칙으로 바꾸면 세 문제가 다 풀린다: 덧셈이 규칙 그 자체이고, 생성기가 남은 양을 보고 값을 내서 막히지 않고, 결과(1)가 늘 같다.

## 6. 추천 코어 3안 → 채택
| 안 | 요약 | 판정 |
|---|---|---|
| A. Drop & Fill(Gemini 1안) | 열마다 합 1.0 채우면 터짐 | **채택** — 로켓 연료통으로 테마화 = «딱1 로켓» |
| B. 물리 버블 머지(Gemini 3안·Grok 2안) | 같은 값 2개 → 2배 | 위 §5 문제로 기각. 연출(튀어 오름)만 가져온다 |
| C. 옛 규칙 강화(Grok 1안) | 같은 값 4개 연결 | «완전히 새 게임» 요청과 안 맞음 |
| D. 동치 공명 → 합성(GPT 1순위) | 같은 값끼리 겹치면 앵커, 앵커 둘을 더하면 1 → 연쇄 | **대안으로 보류** — 동치와 덧셈을 규칙으로 가르는 장점은 크지만 규칙이 두 겹이라 60초 교실 판에서 첫 15초 안에 이해시키기 어렵다. 장점(«식이 화면에 보여야 한다»)만 가져온다 |
| E. 수직선 릴레이(GPT 3안) | 0~1~2 수직선에 이어 붙이기 | A안의 연료통이 곧 세로 수직선이라 A에 흡수 |

GPT 레인의 핵심 지적(채택):
- «4개 붙으면 터짐»에는 수학적 이유가 없어 숙련된 아이는 숫자를 안 읽고 색·위치로 푼다 → 새 규칙은 **수학적으로 맞는 관계(합 = 1)가 곧 터지는 조건**.
- 같은 값 2개 머지는 «같다»와 «더한다»를 같은 행동으로 만든다 → A안은 붓기(더하기)만 있어 충돌이 없다.
- 합쳐지는 순간 식을 0.3~0.5초 보여 줘야 «임의 합성»으로 안 읽힌다 → **발사 때 «1/4 + 0.5 + 25% = 1» 식을 0.5초 띄운다**(GDD §1-3).
- 실제 사례: «Fraction 2048» 류 앱이 있으나 규모·효과 검증 사례는 못 찾음(GPT). 같은 분모만 찾는 게임으로 전락하는 위험.

## 7. 이번 게임 고유의 차별점(복제 위험 없음)
- «합 = 정확히 1» 판정 + 로켓 발사 연출 + 표기 섞어 채우기 보너스 + 무데드락 생성기 + 학년 3단계 + 모둠 릴레이.
- 그림은 전부 새로 만든다(GPT 웹앱 원화 → Firefly 3D). 다른 게임의 캐릭터·UI·음향을 쓰지 않는다.
