4) 분수 오개념 5가지와 게임 규칙으로 드러내기/고치기
분모가 클수록 크다 (1/8 > 1/4): 전체 수 편향. → 같은 값 블록만 터지게 하되, 시각 모델(막대/원)을 동시에 표시. 잘못된 비교 시 “작아 보임” 페널티 또는 힌트 강제. [web:95][web:96]
분자·분모 따로 더하기 (1/2 + 1/3 = 2/5): 독립 정수 취급. → 합체 규칙을 “공통 단위로 맞춘 뒤에만 합체”로. 잘못된 합은 터지지 않고 “오류 블록” 생성. [web:96][web:100]
동치 분수는 다른 수 (1/2 ≠ 2/4): 표기만 다르다고 인식. → 동치 블록은 같은 색/값으로 처리하되, 표기를 다양하게 섞어 표시. 4개 매칭 시 표기 변환 애니메이션. [web:96][web:100]
분수는 항상 1보다 작다 / 크기 감각 부족: 수직선·크기 비교 실패. → 블록 크기나 낙하 속도가 실제 값에 비례. 큰 값이 더 무겁거나 커 보이게. [web:102] Scientific American; [web:177]
통분/약분 이해 부족 + 연산 오적용: 공통분모 없이 더하기. → 합체 전 “단위 맞추기” 미니 액션(블록 쪼개기/합치기) 필수. 성공 시 연쇄 보너스. [web:98][web:100]

게임으로 드러내기: 잘못된 매칭은 터지지 않고 가비지 생성 또는 점수 감소 → 즉각 피드백으로 오개념 교정.

5) “수박 게임식 합체”를 분수에 적용한 사례

구체적 성공 사례 거의 없음 (추정). 검색 결과 Suika 클론은 과일·숫자·행성 합체 위주이며, 분수 교육용으로 설계된 사례는 확인되지 않음. [web:29][web:31][web:105]

잠재 문제점 (추정 + 교육 연구 기반):

“같은 것끼리만 합친다”는 동치·크기 개념을 약화시킬 수 있음 (1/2와 2/4를 다른 것으로 취급).
합체 결과가 단순 2배가 되면 분수 덧셈 원리(통분)와 충돌.
물리 재미가 개념 학습을 압도해 “왜 합쳐지는지” 설명이 부족해질 위험. [web:175] 디자인 연구가 보여주듯 재미와 전이는 별개.

가능한 변형: 같은 값의 블록만 합체 → 더 큰 단위 블록으로, 단 동치 표기는 자동 인식.

추천 코어 루프 3안 (교실 60~90초·4~6명 교대 기준)

안 1: “동치 체인 낙하” (기존 강화형)

낙하 블록에 1/2·0.5·50% 등 동치 표기. 같은 값 4개 인접 시 터짐 + 연쇄. 오개념(분모 크기·따로 더하기)은 잘못된 매칭 시 가비지 생성으로 드러냄.

장점: 기존 익숙, 짧은 판 적합. 재미: 체인·멀티 공격.

출처 기반: Puyo 체인 + Slice Fractions 시각 전이.

안 2: “값 합체 수박형” (물리 + 개념)

컨테이너에 분수 블록 낙하. 같은 값(동치 인정) 2개 충돌 시 합쳐 더 큰 단위 블록(예: 1/4+1/4→1/2). 수박처럼 최대 단위(1) 만들기. 크기 시각화 강조.

장점: 2023~2026 머지 트렌드 반영, 물리 재미. 오개념 교정: 합체 전 단위 맞추기 필수.

출처 기반: Suika + Fraction Ball 크기 강조 + 2048 합체.

안 3: “비교·교환 하이브리드” (Panel de Pon + 교육)

일부 낙하 + 인접 교환 가능. 목표: 특정 크기 비교 완료 또는 동치 그룹 만들기. 특수 블록으로 “통분” 액션. 짧은 목표 클리어 후 교대.

장점: 오개념(크기 비교·동치)을 규칙 자체로 드러냄. 교실 대결 강함.

출처 기반: Panel de Pon 교환 + Motion Math/Fraction Ball 크기 연구.
